# Decision Arena: живая схема экономики Amber

Интерактивная 3D-схема экономики токена Amber. Это один файл `index.html`. Сборка не нужна, сервер не нужен.

**Иллюстрация механики, не реальные данные блокчейна. Токен-режим доступен только там, где он законен.**

## Как открыть
- **На GitHub Pages:** откройте ссылку на страницу. Больше ничего делать не нужно.
- **Локально:** откройте `index.html` в свежем Chrome, Safari или Edge. Нужен интернет, потому что библиотеки грузятся с CDN.
- **Параметры URL:**
  - `?nointro` пропускает вступительный экран.
  - `?lang=en` открывает английскую версию.

## Библиотеки (CDN, версии закреплены)
- three.js 0.160.0 с jsdelivr: `three.module.js` и `examples/jsm`. Используются OrbitControls, EffectComposer, RenderPass, UnrealBloomPass и OutputPass.
- Шрифт Inter (Google Fonts).

## Что важно знать
- **Темп условный.** Счётчики и кошельки — это симуляция: 1 секунда = 5 минут, по 1 матчу на игрока в день. Это не реальные данные сети.
- **Цены Amber в долларах и прогнозов на схеме нет.**
- **Сожжение при минте не входит в счётчик «Сожжено».** Сумма в Amber зависит от рынка, поэтому в счётчик она не попадает.
- **5% турнирного пула пока не распределены.** Решение не принято, на схеме так и подписано.
- **Студия не играет против игроков.** Она получает фиксированный 1% каждого пула.
