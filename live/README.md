# Decision Arena — версия PROD (`/live/`)

Публичная версия. По умолчанию показывает **реальные данные блокчейна Polygon**:

- держателей Amber;
- сжигания на `0x…dEaD`, они летят в чёрную дыру;
- матчи боевого контракта с расшифрованными событиями;
- балансы стейкинга, Банка Студии и пула DEX;
- гномов (ERC‑721): ID, владельцев, картинки из IPFS со ссылками на OpenSea.

При первом открытии история восстанавливается с первого блока. Кнопка «Восстановить историю» в любой момент заново проходит логи с первого блока, по частям. Дальше новые блоки подтягиваются каждые `pollSeconds` секунд.

**Демо.** Переключатель «Блокчейн / Демо» в панели «Данные» (или параметр `?demo`) включает иллюстративные данные. Пока он включён, внизу висит подпись «Демо-данные: симуляция, не блокчейн». Песочницы в prod нет. Эпоха «Будущее» берётся из конфига (`mining.active`), ручной просмотр помечен «предпросмотр».

Найти себя можно по адресу `0x…`, а после настройки `usernameApi` — и по нику.

## Как подключить адреса контрактов

Все настройки лежат в одном блоке `window.ED_CONFIG`. Он общий для обеих версий:

- в исходниках это `src/a_cfg.html`;
- в готовом файле это первый `<script>` в `index.html`.

1. Откройте `src/a_cfg.html` и найдите раздел `contracts`.
2. Впишите адрес контракта (`0x…`, 42 символа) в поле `address` нужного контракта.
   - Пустая строка `''` означает, что контракт ещё не подключён. Сцена подписывает его «скоро».
3. Если знаете блок, в котором создан контракт, укажите его в `fromBlock`.
   - С этого блока начинается восстановление истории.
   - `0` — искать с начала.
4. Можно указать сигнатуры событий в `events` в формате Solidity, строкой или массивом. Например:
   `'endedGame(uint256 indexed id,address indexed winner,uint256 indexed amount)'`.
   - Без `events` контракт всё равно читается: по его балансу Amber и по переводам Amber на его адрес и с него.
5. Пересоберите файлы командой `./build.sh`. Она запишет `v2/index.html` и `live/index.html`.
   - Можно поправить блок `ED_CONFIG` прямо в готовом `index.html` и обойтись без сборки.

### Шахта и эпохи

- `contracts.mining.active: true` — майнинг запущен. Prod переходит в эпоху «Будущее»: шахта становится крупнейшим телом в центре, энергия идёт от неё к гномам.
- `contracts.mining.startBlock` — блок старта майнинга. Его можно не указывать. По нему машина времени показывает смену эпох.
- Пока майнинг не запущен, в prod кнопка эпохи включает только **предпросмотр**. Он отмечен меткой «предпросмотр».

### Юзернейм → адрес

- `usernameApi` — адрес игрового API, например `'https://api.example.com/user/{name}'`.
- Ожидаемый ответ: `{"address":"0x…"}`.
- Пусто — поиск работает только по адресу.

### Облик замка

- `skinResolver` в конфиге или `window.ED_skinResolver = addr => номер` снаружи.
- Функция получает адрес и возвращает номер облика:

| Номер | Облик |
|---|---|
| 0 | каменная крепость |
| 1 | ледяной шпиль |
| 2 | янтарная цитадель |
| 3 | деревянный форт |
| 4 | обсидиановый бастион |
| 5 | небесный храм |

- Без хука замки получают облик так:
  - в dev и демо облик выбирается детерминированно по адресу;
  - в prod на данных блокчейна всем ставится облик по умолчанию (0).

### RPC

- Список `network.rpcs` перебирается по порядку. При ошибке берётся следующий RPC.
- `maxRange` — сколько блоков запрашивать за один `eth_getLogs`.
- Если все RPC недоступны, появляется баннер «Не удалось связаться с публичными узлами Polygon». Сцена сама переходит на демо-данные, а кнопка «Повторить» снова пробует подключиться.

## Параметры адреса

- `?lang=en` — интерфейс на английском. По умолчанию русский, переключатель RU/EN в правом верхнем углу.
- `?nointro` — без заставки.
- `?demo` — в prod сразу открыть демо-данные.
- `?chain` — в dev сразу открыть данные блокчейна.

## Файлы

- `index.html` — один самодостаточный файл. three.js 0.160.0 грузится с jsdelivr через importmap. Нужен только интернет, сервер не нужен. Можно открыть файл напрямую или положить на любой статический хостинг.
- `shots/` — скриншоты из автотеста.
- Исходники лежат в `../src/`, сборка — `../build.sh` (порядок файлов задан в скрипте явно).

Все цифры и сцены иллюстративны. Курса Amber в долларах и прогнозов здесь нет.
